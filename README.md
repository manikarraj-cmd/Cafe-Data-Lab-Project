☕ Cafe Operations & AI Dashboard

An end-to-end Data Science and Machine Learning project that transforms raw restaurant orders into an interactive analytics dashboard and predictive AI model.

🌟 Project Highlights

Data Engineering: Automated script to migrate raw CSV data into a relational SQLite database.

Business Analytics: SQL queries and Pandas aggregations to uncover top products, busy cities, and payment trends.

Machine Learning: A Logistic Regression model (with Feature Engineering) that predicts a customer's payment method with 88% accuracy.

Interactive Dashboard: A premium web application built with Streamlit and Plotly for real-time data exploration.

🛠️ Technologies Used

Python (Pandas, SQLite3)

Machine Learning (Scikit-Learn)

Visualization (Streamlit, Plotly Express, Matplotlib)

🚀 How to Run this Project

1. Install Dependencies:

pip install pandas matplotlib scikit-learn streamlit plotly



2. Setup the Database:
Run the setup script to ingest the restaurant_orders.csv file and create the local SQLite database.

python database_setup.py



3. Run the Analytics Scripts (Optional):

python run_queries.py
python predictive_model.py



4. Launch the Web Dashboard:

python -m streamlit run app.py
